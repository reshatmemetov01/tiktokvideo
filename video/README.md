# «Первые 72 часа в метро» — генератор видео

Анимация рисуется кодом (Canvas 2D) и рендерится покадрово через Playwright → ffmpeg.

- `align.py` — текст сценария + тайминги Whisper → `captions.json` (пословные субтитры; `*жёлтый*`, `!красный!`, `~голубой~`).
- `lib.js` — примитивы, HUD-плашки, персонаж Марк, иконки.
- `world.js` — сцены 1–4 (город, тоннель, вагон, станция).
- `scenes.js` — сцены 5–8, субтитры, таймлайн сцен.
- `audio.py` — синтез фона и звуковых эффектов.
- `render.mjs` — `node render.mjs stills 5,12,30` (контрольные кадры) / `node render.mjs video`.
- `build.sh` — полная сборка в `out/metro72.mp4`.

Ник канала: константа `CHANNEL` в `lib.js`.
Новая озвучка того же текста: заменить `voice.mp3`, пересчитать `whisper_words.json` (faster-whisper, word_timestamps) и запустить `build.sh`.
`align.py` строит `warp.json` — пословную карту «время новой озвучки → базовый таймлайн» (`captions_v1.json`),
по ней сдвигаются анимация и звуковые эффекты.
